# Trivia Prize Game

A simple Python quiz game where players answer trivia questions to win prize money.
Inspired by the show Kaun Banega Crorepati (KBC). Prize money increases with each
correct answer, but the game ends immediately on a wrong answer.

## How to run
1. Make sure Python is installed.
2. Run the file:
   python trivia_prize_game.py
3. Answer each question by typing a, b, c, or d.

## Features
- 5 trivia questions with increasing prize money
- Input validation (only accepts a, b, c, or d)
- Shows running prize money after each correct answer
- Game ends on the first wrong answer
